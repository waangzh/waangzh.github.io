# Kevin 的开发主页

一个用于展示 AI 应用项目、技术方向与 GitHub 的静态网站。

## 技术栈

- HTML5
- CSS3
- Vanilla JavaScript

## 项目结构

```text
.
├─ index.html
├─ data/
│  └─ profile.json
├─ assets/
├─ styles/
├─ scripts/
└─ README.md
```

## 本地预览

```bash
npm run dev
```

或：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 部署

可直接部署到 Vercel、GitHub Pages 或任意静态文件托管平台。
